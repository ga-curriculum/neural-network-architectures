# <picture><img src="https://ga-curriculum.github.io/universal-resources-internal/ga-logos/ga-red-cog-128x128.png" alt="" height="48" align="absmiddle"></picture> [Deep Learning ] - Neural-Network-Architectures (3 of 3) 

**Learning Objective:** 

- Understand convolutional layers, pooling, and filters.
- Explain RNNs, their structure, and sequence modeling.
- Fine-tune pre-trained models for specific tasks (e.g., classification, object detection).

**Format:** Github and deck   

**About:** This unit builds on the foundations of deep learning by exploring advanced neural network architectures. Students will delve into Convolutional Neural Networks (CNNs) for image data, Recurrent Neural Networks (RNNs) for sequential data, and Transfer Learning with pre-trained models for efficient task-specific tuning. Through these techniques, students will gain practical insights into building and optimizing models to solve real-world problems.

**Prerequisites:** 
1. Basic Python programming
1. Basics of building neural networks with pytorch (module 2 of the Deep Learning Unit)
